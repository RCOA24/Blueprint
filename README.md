# Blueprint Group Next.js website

This TypeScript Next.js App Router project migrates the supplied 14-page static website. Its page copy, images, video, navigation, galleries, filters, career listings, and visual styles are carried into this project.

## Develop and build

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
npm.cmd run test:e2e
```

`npm.cmd run build` creates the fully static `out/` directory. There is no server, database, PHP endpoint, or automated email delivery. The content is generated by typed templates in `lib/site.ts`; shared page rendering is in `components/SitePage.tsx`; browser interactions are in `components/SiteInteractions.tsx`. The appointment form and email URL helpers are in `components/AppointmentForm.tsx` and `lib/email.ts`.

The browser smoke test uses an installed Chrome browser. To also compare unchanged page HTML with the original export, set `BLUEPRINT_REFERENCE_DIR` to that export's `dist` directory before running the test. The contact page follows the D’ Embassy appointment flow and is intentionally different.

## Hosting on Hostinger

Set `NEXT_PUBLIC_SITE_URL=https://YOUR-FINAL-DOMAIN` **before the production build** so canonical URLs, Open Graph links, sitemap, robots.txt, and structured data use the correct domain. The fallback is `https://blueprint.ky`, which must be reviewed if launching on a staging or alternate domain.

1. Check the actual plan and the domain's document root in hPanel. Hostinger's current documentation describes Node.js hosting for Business/Unlimited plans, but this build needs only static hosting.
2. Back up the current website and rewrite rules. Upload the **contents** of `out/` to the domain's document root, not the `out` folder itself.
3. Ensure `index.html` is served for directory routes, such as `/services/` and `/projects/north-side/`. `trailingSlash: true` emits an `index.html` in every page directory. Remove or update old WordPress rewrites only after confirming they will not interfere with other applications.
4. Connect the custom domain, enable HTTPS in hPanel, and verify the root page, nested routes, direct refreshes, images, video, sitemap, and robots.txt on the live host.
5. Check old-to-new redirects separately if replacing an existing website. The export does not know every previous WordPress URL.

## Email inquiry behavior

The contact page has one appointment request form, based on the D’ Embassy flow: service prefill, required future preferred date, Cayman Islands time preference, optional message, and clear confirmation guidance. Clicking **Request Appointment** opens a populated Gmail Web draft. The visitor must review and manually send it; a click does not prove delivery or confirmation. If Gmail is blocked, the visitor can allow pop-ups and click the same button again. The site does not store form entries. The business email remains `info@blueprint.ky` from the supplied source. The displayed physical address is Unit 3C, Grand Cayman, 80 Shedden Road, Elizabethan Square, Amerigo House, KY1-1503, Cayman Islands.

## Launch verification

Check 320, 375, 768, 1024, 1440 and ultrawide viewports in Chrome, Edge, Firefox, Safari, Android, and iOS where available. Exercise navigation, mobile menu, filters, gallery dialog, video control, career disclosures, service/product prefill, native form validation, all appointment compose options, keyboard focus, and reduced-motion behavior. Send a test draft manually only after the business confirms the recipient. Verify the deployed domain and account settings in hPanel; local builds cannot establish those facts.
